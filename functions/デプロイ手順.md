# 受付（Firebase Functions）のデプロイ手順

`functions/index.js` を直したときは、**push だけでは反映されない。**
GitHub Pages が配るのはアプリ側（HTML/CSS/JS）だけで、受付は Google 側にあるため。
下のコマンドで別に上げる。

やるのは **Node が入っている端末**（担当k）。
アプリ側は触らないので、この作業で現場のアプリが止まることはない。

---

## 1回目だけ要るもの

Node.js（18以上）が入っていること。確認：

```bash
node -v
```

Firebase CLI を入れる：

```bash
npm install -g firebase-tools
```

Google アカウントでログイン（ブラウザが開く）：

```bash
firebase login
```

---

## 毎回やること

### ① 最新を取ってくる

```bash
git pull
```

### ② functions フォルダへ移動

```bash
cd mitsumori/functions
```

### ③ 必要なものを入れる（初回と package.json が変わったときだけ）

```bash
npm install
```

### ④ 上げる

```bash
firebase deploy --only functions:estimateFromPhotos --project mitsumori-35e9d
```

3〜5分かかる。最後に `Deploy complete!` と出れば成功。


## うまくいかないとき

| 出るもの | 意味 | どうするか |
|---|---|---|
| `Error: Failed to get Firebase project` | プロジェクトが違う | `--project mitsumori-35e9d` が付いているか確認 |
| `HTTP Error: 403` | 権限が無い | そのGoogleアカウントが `mitsumori-35e9d` の編集者か確認 |
| `functions: command not found` | CLI が入っていない | 上の `npm install -g firebase-tools` |
| デプロイは通るのに相場が増えない | 上げたのが古いコード | `git pull` を先にやったか確認。`git log -1` で最新か見る |

## 2026/8/7 に何を直したか

**症状**: 概算の項目に「世の中の相場」が1件も出ない。全部「よつばの単価」だけ。

**調べた結果**（`tools/test-ai.html` と実データ）:

- 受付・App Check・画面はすべて正常だった
- AIは動いていた（直近4件のうち3件が `source:'ai'`・全項目 `未確定`）
- **AIが `marketAmount` を返したり返さなかったりしていた**
  （20項目中11件返した回と、16項目すべて null の回があった）

**原因**: 聞き方（`SYSTEM`）の

> 写真から読み取れないこと（寸法・型式・kW・数量）を推測で埋めないでください

が**相場にも効いていた**。加えて schema の説明が「分からなければ null」で、
null が楽な逃げ道になっていた。
寸法や型式は推測してはいけないが、**相場はもともと当てにいく数字**で性質が逆。

**直したこと**:

1. `SYSTEM` の禁止対象を「寸法・型式・kW・数量（＝ qty・cost・trade・persons・hours）」に限定
2. 「marketAmount は禁止の対象外。必ず入れる。null は例外」を足した
3. schema の `marketAmount` の説明から「分からなければ null」を外した

**この先ここを触るときの注意**: `marketAmount` の説明に
「分からなければ null」と書き戻さないこと。それがこの症状の元。
