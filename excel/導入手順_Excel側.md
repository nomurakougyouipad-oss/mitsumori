# Excel側の導入手順（アプリのCSVを読み込む）

アプリは xlsm を作りません。CSVを出し、Excel側のマクロが内訳書に書き込みます。
**xlsmの構造（プルダウン・マクロボタン）には一切触れない設計です。**

## 1. マクロの取り込み（各自のxlsmに1回だけ）

1. Tekkosho_Mitsumorisho.xlsm（自分のファイル）を開く
2. Alt+F11 でVBEを開く
3. メニュー ファイル → **ファイルのインポート** → 同梱の `ImportCSV.bas` を選ぶ
4. 保存して閉じる。Alt+F8 →「アプリのCSVを読み込む」で実行できます
   （よく使うなら内訳書にボタンを置いて登録してもOK）

## 2. 使い方

1. アプリの「見積の確認」→ **Excelへ渡す** でCSVを保存（iPhoneなら共有→ファイルに保存）
2. CSVを事務所のPCへ（共有フォルダ等）
3. Excelで Alt+F8 →「アプリのCSVを読み込む」→ CSVを選ぶ
4. 内訳書に表紙・率・明細・端数調整・担当者名が入ります
5. **H86（御見積金額）がアプリの表示と一致するか必ず確認**
6. あとは今まで通り「案件マスターに登録」→ 別名保存

## 3. 仕組みの注意（重要）

- **率も書き込みます**（B12:H12）。材料B12と労務C12だけ「1＋率」の形（15%→1.15）。
  これはExcel原本の式に合わせたもので、アプリが自動で変換します。
- **材料のH列（計上金額）は値で上書きします**（手打ち・単価待ちの品目は
  Excelの品名プルダウンに無く、式では計算できないため）。
  マクロは書き込み前に毎回H20:H34の式を復元してから使う行にだけ値を入れるので、
  次にExcelだけで見積を作るときも壊れません。
- 法定福利費オフの見積は E12=0 で渡します（Excel側も0円になります）。
- 担当者名は **N1セル** に入ります（印刷範囲外想定。場所を変えたい場合は
  ImportCSV.bas の先頭 `STAFF_CELL` を書き替え）。

## 4. 発注メールの署名を直す（任意・推奨）

今のマクロは署名の名前を**ファイル名**から取るため、事務所の1ファイルから
発注すると事務員さんの名前で出ます。`ImportCSV.bas` に入っている
**関数「担当者名を取得」**（N1→空ならファイル名の順で読む）を、
発注メール作成マクロの名前取得部分から呼ぶように置き換えてください。

Macro_Code.txt（マクロの控え）をこの作業フォルダに入れてもらえれば、
置き換え済みの完全版を作ってお渡しします。

## 5. 行数の上限

内訳書の行数はExcel側の枠のまま：材料15行／労務10行／移動7行／外注7行。
超えるとアプリが書き出し時に警告します（超えた分はCSVに入りません）。
